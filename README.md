# 장마가 오기 전에

**사고, 침수, 보수 이력, CCTV 데이터를 결합한 하수관 위험 우선순위 분석**

> 🏆 명지대학교 창의적 SW 경진대회 빅데이터 분석 부문 **최우수상** (2026) · TEAM 톰과젤리

공공데이터 5종을 결합해 하수관 결함을 싱크홀과 침수 두 축의 재난 위험으로 환산하고, 자치구별 조사·보수 우선순위를 산출하는 분석 시스템이다. 서울 전역 조사 구역 241개를 도출했으며, 2024년 실제 싱크홀 사고가 발생한 지역이 사고 정보를 사용하지 않은 목록의 상위권에 포함되는 것을 확인했다.

## 문제

2025년 3월 강동구 명일동에서 대형 지반침하로 인명 피해가 발생했다. 사고조사위원회 조사 결과 이 지점의 하수관 결함은 3년 전 실태 조사에서 이미 발견되어 있었으나 보수로 이어지지 못했다. 서울에서 정비가 필요한 하수관은 수천 km인데 예산은 한정되어 있다. 검사와 진단 체계는 있지만 **무엇부터 조치할지 정하는 기준**이 없다는 것이 이 프로젝트의 출발점이다.

## 접근 — 조사와 보수를 분리

| 단계 | 질문 | 방법 | 데이터 |
|---|---|---|---|
| 1 | 어디부터 조사할 것인가 | 반복 보수 이력 × 사고 × 침수 공간 결합 → 구역 군집화 | 100% 실데이터 |
| 2 | 무슨 결함이 있는가 | CCTV 영상 결함 자동 탐지 (YOLOv8) | AI-Hub 33,000장 학습 |
| 3 | 무엇부터 고칠 것인가 | 결함 → 싱크홀·침수 2축 위험 점수 환산 | 가상 구간 시연 |

## 주요 결과

### 조사 우선순위 (실데이터)

- 3회 이상 반복 보수된 지점 **6,447곳**에 주변 250m 사고, 100m 침수 이력을 결합
- DBSCAN(eps 150m, 최소 5지점) 군집화로 **조사 구역 241개** 도출, 이 중 26곳은 반경 내 실제 사고 이력 보유
- 2024년 8월 실제 싱크홀 사고 발생 지역(서대문구 연희동)이 **사고 정보를 사용하지 않은 목록의 7위**에 포함

### 검증

| 검증 | 결과 |
|---|---|
| 사례-대조 공간 검증 | 사고 지점 250m 내 반복 보수 밀도가 무작위 대조점의 **1.47배** (순열검정 p=0.0001), 사고의 82%가 인접 / 500m에서는 차이 소멸(1.07배, p=0.21) |
| 가중치 민감도 | ±30% 무작위 교란 200회에도 상위 10개 순위 **83.8% 유지** (±10% 92.4%, ±20% 87.3%) |
| 독립 신호 교차 | 가중치 설계에 사용하지 않은 포트홀 신고량 × 침하사고 상관 ρ=0.412 (p=0.041) |
| 탐지 오류 교란 | confidence ±20%에 83.8% 유지, 결함 20% 미탐 시 55.8%로 하락 → recall 우선 운영 규칙 도출 |

### 분석 설계의 근거

- 지반침하 사고 1,584건 직접 분석 — 원인 1위 하수관 손상 **41.0%**, 사고의 **48.3%**가 우기(6~8월) 집중
- 구별 침하사고 × 침수 이력 상관계수 ρ=0.151, 순열검정 p=0.47 → 유의한 상관 없음, **2축 분리** 설계의 근거

![위험 매트릭스](risk_matrix.png)

### AI 결함 탐지

YOLOv8, 학습 33,000장 / 미학습 테스트 3,300장 평가, 전체 mAP50 **0.693**. 위험 가중치가 큰 토사퇴적(0.941), 이음부 단차(0.794)에서 성능이 가장 높다.

![탐지 결과](detection_samples/det_1_DS_000018_conf0.96.png)

### 위험 번역 엔진

```
위험 점수(구간) = Σ [ 가중치 × 심각도 × 신뢰도 ]   — 싱크홀 축, 침수 축 각각 산출
```

가중치는 학습이 아닌 세 가지 근거에서 설계했다. 결함과 사고가 연결된 공개 데이터가 없고, 사고 다발지 결함에 높은 가중치를 부여하면 순환 논리가 되기 때문이다.

- **[A] 사고 통계** — 사고 1,584건 원인 분석 + 서울시 조사 접합부 결함 46.3% → 이음부 계열에 싱크홀 최고 가중
- **[B] 수리 계산** — Manning 공식: 퇴적 30%에서 통수능 84%, 70%에서 20% → 토사퇴적에 침수 최고 가중
- **[C] 판정 기준** — 환경부 하수관로 상태등급 → 결함 크기별 심각도 배율

## 활용 데이터

| 데이터 | 형식 | 규모 | 출처 |
|---|---|---|---|
| 지반침하 사고정보 | API (JSON) | 1,584건 (2018~25) | 국토교통부 지하안전정보시스템 |
| 침수흔적도 | SHP (EPSG:5179) | 폴리곤 21,412개 (2022~25) | 서울시 공간정보 |
| 포트홀 보수 이력 | XLSX | 94,469건 (2023~25) | 서울 열린데이터광장 |
| 하수관로 CCTV 결함 이미지 | JPG + COCO | 47만 장 중 서브셋 33,000장 | AI-Hub |
| 행정경계 | GeoJSON | 자치구 25개 | 서울시 |

정형 데이터 4종과 비정형 데이터 1종을 좌표계 통일(EPSG:5179 → WGS84)과 주소 지오코딩(VWorld API, 성공률 98.8%)을 거쳐 하나의 공간 기준으로 결합했다.

> **AI-Hub 이미지 데이터는 이용약관상 제3자 재배포가 금지되어 이 저장소에 포함하지 않았다.** 재현 시 AI-Hub에서 「하수관로 결함 데이터셋」을 직접 내려받은 뒤 `scripts/build_subset.py`와 `scripts/coco_to_yolo.py`를 실행하면 동일한 학습 데이터가 구성된다. 학습을 재현하지 않아도 포함된 가중치(`sewer_best.pt`)로 탐지 파이프라인은 그대로 실행할 수 있다.

```

```

## 실행

```bash
pip install pandas matplotlib scikit-learn pyshp folium ultralytics openpyxl
python scripts/demo_e2e.py        # 탐지 → 위험 점수
python scripts/build_map.py       # 위험 지도 생성
python scripts/build_dashboard.py # 대시보드 생성
```

지도와 대시보드는 생성 후 브라우저로 열면 되며, 서버가 필요 없다. 두 HTML을 같은 폴더에 두면 대시보드의 주소 클릭 → 지도 이동 연동이 동작한다.

API 키(공공데이터포털·VWorld·AI-Hub)는 코드에 포함되어 있지 않으며 수집 스크립트 실행 시 명령행 인자로 전달한다.

## 분석의 한계

1. 개별 사고를 예측하는 도구가 아니라 조사·보수 우선순위를 선별하는 **스크리닝 도구**다.
2. 학습용 CCTV 이미지에 위치 정보가 없어 보수 우선순위의 구간 구성과 위치는 가상이다. 자치구 조사 기록이 연계되면 실제 주소로 전환된다.
3. 침수 이력에는 최근 배수 개선 사업의 효과가 반영되지 않았다.
4. 반복 보수 위치는 번지 단위 근사이므로 지점이 아닌 구역(150m 군집) 단위로 추천하도록 설계했다.
